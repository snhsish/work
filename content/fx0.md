# fx0

I built and managed **fx0** between **February 2025 to September 2025**.

Take some time and read [Story Behind](#story-behind) this project :D

## Overview

**fx0** _was_ a fast, minimal and unified AI chat application which routes multiple models into one place. It lets you access various models from different providers through a single web UI. Instead of paying for multiple AI subscription, you can use fx0 to access all of them in one place.

## What I Worked On

- AI routing and multiple model and provider integration and support
- Building a web UI and dashboard for all the models and providers
- Building a single subscription layer and payment system for the users to access the models
- Building a simple and fast chat interface with history and context support for the users to interact with the models

## Tech Stack

- Next.js
- TypeScript
- MongoDB
- Node.js
- Tailwind CSS and other component libraries

### Challenges and Learning

- One of the main challenges I faced was integrating multiple AI models from different providers, each with its own API and authentication methods. I had to ensure that the routing logic was efficient and that the user experience remained seamless despite the complexity behind the scenes.
- Another challenge was implementing a single subscription layer and payment system that could handle different pricing models and billing cycles. I had to research and implement a solution that was both secure and user-friendly.

## Story Behind

I was early on this project idea. Back when [@theo](https://twitter.com/theo)'s `t3.chat` didn't exist. But my time for execution and focus was limited. I had a lot of ideas and wanted to build something that would make AI more accessible to everyone. I wanted to create a platform where users could easily switch between different AI models without having to manage multiple subscriptions or interfaces. But after theo released `t3.chat`, I was glad someone had a similar idea and executed it well. Soon I dropped the project and started working on other things. This is just a small showcase and archive of what I built and managed during that time.
