# Orcrys Technologies Pvt. Ltd.

I worked as a **Software Engineer Intern** at Orcrys Technologies Pvt. Ltd. from **May 2026 to July 2026**.

## Overview

The company was commited to building real-world solutions for education, technology and businesses. During my internship, I was involved in various projects that allowed me to apply my skills in software development and gain hands-on experience in a professional environment.

## What I Worked On

- **Lead Project Developer** at [Edquate](#edquate)
- Built landing pages that increased user engagement and improved the overall user experience.
- Developed dashboards that provided valuable insights and analytics for users.

## Tech Stack

- Next.js
- TypeScript
- PostgreSQL
- Docker
- Node.js
- Tailwind CSS and other component libraries

### Challenges and Learning

- I had no production level experience with Docker and Next.js before this. However, I quickly adapted and learned to use these effectively to contribute to the project.
- Server management was a new area for me, and I gained valuable experience in deploying and maintaining applications in a production environment.
- I learned to work with a team of developers, collaborating on code reviews, and integrating various components of the platform.

## Edquate

Edquate is an innovative platform designed to enhance the learning experience for students and educators. As the lead project developer, I was responsible for designing and implementing key features of the platform. My contributions included:

- Designing and developing the landing page (and other pages) using Next.js and TypeScript, ensuring a responsive and user-friendly interface.
- Implementing dashboards that provided real-time analytics and insights for users, helping them track their progress and performance.
- Collaborating with the team to integrate various APIs and services, enhancing the functionality of the platform.
- Conducting thorough testing and debugging to ensure the platform's stability and performance.
